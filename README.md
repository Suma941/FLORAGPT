# FloraGPT

FloraGPT is an AI-powered plant care assistant that allows users to enter any plant name and instantly receive plant care guidance generated by the Gemini AI API. Built with Flask, HTML/CSS/JS, featuring a premium glassmorphism design and dynamic animations.

## Features
- Instant AI plant care guides (Overview, Watering, Sunlight, Soil, Fertilizer, Diseases, Tips)
- Modern nature + AI aesthetic with Glassmorphism
- Dynamic, mouse-responsive parallax background with animated elements
- Responsive design for Mobile, Tablet, and Desktop
- Lightweight Python Flask backend

## Local Setup Instructions

1. **Prerequisites**: Ensure you have Python 3.8+ installed.
2. **Clone/Download** this repository.
3. **Navigate** to the project directory:
   ```bash
   cd FloraGPT
   ```
4. **Create a Virtual Environment** (Recommended):
   ```bash
   python -m venv venv
   # Windows
   venv\Scripts\activate
   # macOS/Linux
   source venv/bin/activate
   ```
5. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```
6. **Set Environment Variables**:
   - Open the `.env` file.
   - Replace `YOUR_API_KEY_HERE` with your actual Gemini API key from [Google AI Studio](https://aistudio.google.com/).
7. **Run the Application**:
   ```bash
   python app.py
   ```
8. **View in Browser**: Open `http://localhost:5000`

## Deployment to Render

FloraGPT is ready to be deployed on Render!

1. Create a new Web Service on Render and connect your GitHub repository containing this project.
2. Use the following settings:
   - **Environment**: Python 3
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `gunicorn app:app`
3. Under **Environment Variables** in the Render dashboard, add:
   - `GEMINI_API_KEY` = `<Your Gemini API Key>`
4. Click **Create Web Service**. Your app will be live once the build finishes!
